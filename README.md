# Willow Lily Estate & Inn

Premium wedding venue portfolio concept by A. Halliwell Studio.

## Deploy
This is a zero-build static site. Upload the full contents to GitHub and import the repository into Vercel. Framework preset: Other. No build command required. Output directory: `.`

## Important
The inquiry form is a front-end concept interaction and does not transmit personal data. Connect it to the client's approved CRM/form endpoint before production use. Stock/concept imagery must be properly licensed before public commercial launch.
